## Validation commands

Run the complete offline suite from the Sandbox root:

```powershell
python -B -m unittest discover -s tests
```

Run the focused MNSUTB compliance suite:

```powershell
python -B -m unittest tests.test_mnsutb_source_detail_compliance
```

Expected warning and error logs are produced by deliberate failure-path tests.
Success is determined by the test exit code and final `OK`.
